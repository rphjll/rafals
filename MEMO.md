# Mémo rafals — mes gestes

1. **Reprendre** : écrire `continuer` dans Claude Code (même dans une nouvelle conversation).
2. **Lancer** : double-clic sur `demarrer.bat` (créé au lot 0.1).
3. **Sauvegarder** : double-clic sur `sauver.bat` (créé au lot 0.1), puis une petite phrase.
4. **Laisser Claude avancer seul** : « fais les lots X à Y, tout seul ».
5. **Finir la journée** : `dodo`.
6. **Voir l'avancement** : `.doc/SUIVI-DEV.md`.
7. **Sur un nouveau PC** : après le premier `demarrer.bat`, lancer une fois `preparer-stockage.bat` (le placard à fichiers), puis soit `restaurer_base.bat` (tes données sauvegardées), soit `charger-metiers.bat` et `charger-communes.bat` (listes de départ).
8. **Devenir administrateur** (une seule fois) : créer ton compte dans rafals, puis `nommer-premier-administrateur.bat`.
9. **Valider un lot** : l'essayer, puis dire « je valide le lot X.Y » (seul toi passes un lot à ✅).
