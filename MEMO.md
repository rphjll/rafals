# Mémo rafals — mes gestes

1. **Reprendre** : écrire `continuer` dans Claude Code (même dans une nouvelle conversation).
2. **Lancer** : double-clic sur `demarrer.bat` (créé au lot 0.1).
3. **Sauvegarder** : double-clic sur `sauver.bat` (créé au lot 0.1), puis une petite phrase.
4. **Laisser Claude avancer seul** : « fais les lots X à Y, tout seul ».
5. **Finir la journée** : `dodo`.
6. **Voir l'avancement** : `.doc/SUIVI-DEV.md`.
7. **Valider un lot** : l'essayer, puis dire « je valide le lot X.Y » (seul toi passes un lot à ✅).
