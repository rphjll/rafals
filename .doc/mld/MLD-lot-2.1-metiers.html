Légende

PKidentifiant unique de la ligne. FKnuméro d'une ligne d'une autre table. (1,n)au moins un. (0,n)zéro, un ou plusieurs. (0,1)zéro ou un. (1,1)un et un seul. lecturela 1re cardinalité est du côté de la table de gauche. Ex. « range · (1,n) —— (1,1) » : une catégorie range au moins un métier ; un métier est rangé dans une et une seule catégorie.

Les autres rubriques

CATEGORIE_METIER

Les « dossiers » de métiers.

  • code — identifiant stable, ex. « maison-travaux » (unique)
  • nom — ex. « Maison & travaux »
  • ordre — place dans la liste (1, 2, 3…)
  • est_active — oui / non (désactiver au lieu de supprimer)

METIER

  • code — ex. « plombier », « autre » (unique)
  • nom — ex. « Plombier »
  • mots_cles — liste, ex. « plomberie, fuite, chauffagiste, sanitaire »
  • est_active — oui / non : un métier désactivé n'est plus proposé pour les nouvelles annonces

PROPOSITION_METIER

« Mon métier n'est pas dans la liste ».

  • nom_propose — ex. « Cerf-voliste »
  • statut — « en_attente », « acceptee » (nouveau métier créé), « remplacee » (un métier existant convient), « refusee »
  • propose_le, decide_le
  • metier_retenu_id — le métier créé ou choisi ; vide si en attente ou refusée

Exemples de vraies lignes

CATEGORIE_METIER n° 4 : code « maison-travaux », nom « Maison & travaux », ordre 4.
METIER n° 58 : categorie_id = 4, code « plombier », nom « Plombier », mots-clés « plomberie, fuite, chauffagiste, sanitaire ».

Traduction : « Plombier » est rangé dans le dossier « Maison & travaux » ; Mme Dupont le trouve en tapant « plom », « fuite » ou « chauffagiste ».

PROPOSITION_METIER n° 3 : propose_par_id = 21, nom « Cerf-voliste », statut « acceptee », metier_retenu_id = 301, decide_par_id = 5.

Traduction : Nadia (compte n° 21) a proposé « Cerf-voliste » ; Raphael (compte n° 5) l'a accepté, ce qui a créé le métier n° 301.

PROPOSITION_METIER n° 4 : propose_par_id = 22, nom « Plombier chauffagiste », statut « remplacee », metier_retenu_id = 58.

Traduction : Tom a proposé « Plombier chauffagiste » ; Raphael a répondu que « Plombier » (n° 58) existe déjà. Un même métier peut donc être retenu pour plusieurs propositions (0,n).

Recherche sans tenir compte des accents : la base apprend à ignorer les accents (« electricien » trouve « Électricien »). Pas dans ce lot : l'écran de choix d'un métier et l'administration des métiers (lot 2.2) ; le lien entre un prestataire et ses métiers (lot 2.3).
