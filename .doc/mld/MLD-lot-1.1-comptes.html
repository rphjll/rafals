Légende

PKidentifiant unique de la ligne (un numéro donné par la base). FKnuméro d'une ligne d'une autre table (ici : le compte à qui appartient la ligne). (0,n)côté COMPTE : un compte a zéro, une ou plusieurs sessions (ou jetons). (1,1)côté SESSION / JETON_MAIL : chacun appartient à un et un seul compte.

Les autres rubriques de chaque table

COMPTE

  • email — adresse mail, unique, enregistrée en minuscules
  • mot_de_passe_hache — mot de passe brouillé (illisible, même par l'administrateur)
  • prenom, nom, telephone
  • date_naissance — pour la règle des 16 ans
  • email_verifie_le — date du clic sur le lien ; vide = pas encore vérifié
  • echecs_connexion — mauvais mots de passe de suite (remis à 0 après une connexion réussie)
  • bloque_jusqu_au — fin du blocage de 15 min ; vide = pas bloqué
  • derniere_connexion_le — pour les comptes inactifs (3 ans)
  • cree_le

SESSION

« Rester connecté 30 jours » sur un appareil.

  • jeton_hache — le « badge » secret gardé par le navigateur (brouillé dans la base)
  • appareil — ex. « Chrome sur Android »
  • cree_le, expire_le (création + 30 jours)
  • fermee_le — clic sur « Se déconnecter » ; vide = active

JETON_MAIL

Les liens envoyés par mail.

  • usage — « verification » (adresse) ou « mot_de_passe » (mot de passe oublié)
  • jeton_hache — le secret du lien (brouillé dans la base)
  • cree_le, expire_le (mot de passe : 1 heure)
  • utilise_le — un lien ne sert qu'une fois ; vide = pas encore utilisé

Exemples de vraies lignes

COMPTE n° 1 : email dupont.marie@gmail.com, prénom Marie, nom Dupont, né le 12/03/1972, email_verifie_le = 27/09/2026 20:02, echecs_connexion = 0.
SESSION n° 7 : compte_id = 1, appareil « Chrome sur Android », expire_le = 27/10/2026.

Traduction : Mme Dupont a vérifié son adresse le 27/09 à 20 h 02 ; elle est connectée sur son téléphone jusqu'au 27/10 sans retaper son mot de passe.

COMPTE n° 2 : email karim.plomb@gmail.com, email_verifie_le = vide, echecs_connexion = 5, bloque_jusqu_au = 28/09/2026 14:15.
JETON_MAIL n° 3 : compte_id = 2, usage « verification », utilise_le = vide.

Traduction : Karim n'a pas encore cliqué sur le lien de vérification reçu par mail ; il s'est trompé 5 fois de mot de passe et ne peut plus essayer avant 14 h 15.

SESSION n° 8 : compte_id = 1, appareil « Edge sur Windows ».

Traduction : Mme Dupont est aussi connectée sur son ordinateur : un compte peut avoir plusieurs sessions (0,n), mais une session appartient à un seul compte (1,1).
